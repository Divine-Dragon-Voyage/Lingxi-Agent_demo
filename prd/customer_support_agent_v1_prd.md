# 客户支持智能体 V1 产品需求文档

## 1. 产品概述

### 1.1 产品定位

客户支持智能体是一套面向企业客户互动场景的对话式智能体平台。

企业可以创建不同角色的智能体，并将智能体接入 LiveChat 等客户沟通渠道。智能体可基于人设、流程、知识库、技能、防护措施、环境变量和会话上下文，完成客户咨询接待、销售线索收集、售前答疑、售后支持、问题分流、业务查询和转人工等对话任务。

### 1.2 产品目标

V1 版本目标是完成客户支持智能体的核心配置、发布、渠道接入和运行监控能力，使企业可以完成以下工作：

1. 创建并配置智能体。
2. 配置智能体人设、流程、知识库、技能、防护措施和环境变量。
3. 将已发布智能体接入 LiveChat 渠道。
4. 通过流程调度知识库、技能和转人工。
5. 查看智能体在真实渠道中的运行数据和会话记录。
6. 使用测试面板验证草稿配置效果。

### 1.3 目标用户

| 用户角色 | 使用目标 |
|---|---|
| 企业管理员 | 配置智能体、知识库、技能、渠道和运行规则 |
| 运营人员 | 维护流程、知识内容、防护措施和渠道接待配置 |
| 客服 / 销售 / 客户支持负责人 | 查看智能体接待效果、会话记录和转人工情况 |

## 2. 核心对象定义

### 2.1 智能体

智能体是企业配置的对话式服务角色，用于在客户沟通渠道中自动接待用户消息。

智能体包含以下配置：

- 基础信息
- 人设
- 记忆
- 模型异常话术
- 流程
- 技能添加关系
- 知识库添加关系
- 防护措施
- 环境变量
- 监控数据

### 2.2 流程

流程用于定义智能体在特定业务场景下应遵循的处理规则。

流程由流程名称、触发器和内容组成。智能体在对话过程中识别到用户意图与触发器匹配时，会参考流程内容执行对应处理。

流程可以调度以下能力：

- 追问用户
- 检索知识库
- 调用技能
- 转人工
- 回复用户

### 2.3 知识库

知识库是企业维护的公共知识资源，用于为智能体提供事实依据。

知识库按知识文档维度管理。一个 URL 或一个文件对应一条知识文档。

### 2.4 技能

技能是智能体可调用的外部能力包，用于让智能体在对话中执行查询、提交、创建、通知、检索外部系统数据等动作。

技能通过上传文件导入，导入成功后可被智能体添加使用。

### 2.5 防护措施

防护措施用于为智能体设定行为边界，控制智能体在对话中的回复范围、风险处理方式和会话终止规则。

当用户消息或智能体回复触发防护措施时，系统按照配置执行对应操作。

### 2.6 环境变量

环境变量用于管理当前智能体运行过程中可引用的变量，例如接口地址、账号、Token、业务参数、渠道参数等。

环境变量只对当前智能体生效。

### 2.7 渠道

渠道是用户消息进入智能体的入口，也是智能体将回复发送给用户的出口。

当前版本支持 LiveChat 渠道。

## 4. 全局规则

### 4.1 草稿配置与已发布配置

智能体存在两类配置：

| 配置类型 | 说明 |
|---|---|
| 草稿配置 | 编辑智能体时保存的配置，用于测试面板验证 |
| 已发布配置 | 真实渠道接待用户时使用的配置 |

规则：

1. 编辑智能体详情内配置时，变更保存到草稿配置。
2. 测试面板使用草稿配置。
3. 点击发布后，草稿配置覆盖已发布配置。
4. 真实渠道只使用已发布配置。
5. 渠道配置单独保存生效，独立于智能体发布流程。

### 4.2 智能体发布校验

点击发布时，系统校验以下字段：

| 字段 | 校验规则 |
|---|---|
| 智能体名称 | 必填 |
| 系统提示词 | 必填 |

校验通过后，草稿配置发布为已发布配置。

### 4.3 智能体发布覆盖范围

智能体发布覆盖以下配置：

- 基础信息
- 人设
- 记忆
- 模型异常话术
- 流程
- 技能添加关系
- 知识库添加关系
- 防护措施
- 环境变量

### 4.4 资源变更生效规则

| 变更类型 | 生效规则 |
|---|---|
| 智能体详情内配置变更 | 保存到草稿配置，发布后影响真实渠道 |
| 智能体添加知识库关系 | 发布后影响真实渠道 |
| 知识库文档内容更新 | 对已添加该知识的智能体即时生效 |
| 技能关闭 | 系统同步解除相关智能体的技能绑定关系 |
| 技能删除 | 系统同步解除相关智能体的技能绑定关系 |
| 渠道配置变更 | 保存后按渠道配置生效 |

## 7. 智能体配置

### 7.1 智能体

智能体配置包含：

- 基础信息
- 人设
- 记忆
- 模型异常话术

### 7.2 基础信息

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 智能体头像 | 否 | 用于展示智能体形象 |
| 智能体名称 | 是 | 用于标识当前智能体 |
| 智能体简介 | 否 | 用于说明智能体用途、能力范围或服务场景 |

### 7.3 人设

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 系统提示词 | 是 | 定义智能体身份、任务边界、表达方式和业务处理原则 |
| 回复语言 | 否 | 控制智能体回复用户时使用的语言 |
| 回复风格 | 否 | 控制智能体回复语气和表达方式 |

#### 7.3.1 回复语言选项

- 与用户语言相同
- 中文
- 英文
- 日文
- 泰文
- 越南文

#### 7.3.2 回复风格选项

- 自然
- 正式
- 简洁
- 耐心
- 热情

### 7.4 记忆

记忆用于控制智能体是否参考历史会话上下文。

#### 7.4.1 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| 记忆开关 | 开关 | 默认关闭 |
| 记忆有效期 | 单选 + 滑杆 | 开启记忆后展示 |
| 历史会话数 | 滑杆 | 开启记忆后展示 |

#### 7.4.2 记忆有效期

| 选项 | 说明 |
|---|---|
| 自定义 | 默认选项，展示有效期滑杆 |
| 永久有效 | 选择后隐藏有效期滑杆 |

自定义有效期滑杆范围：1 天 - 365 天。

默认值：7 天。

#### 7.4.3 历史会话数

历史会话数用于控制智能体最多参考多少轮历史会话。

滑杆范围：1 轮 - 50 轮。

默认值：10 轮。

#### 7.4.4 记忆作用域

记忆以「智能体 + 渠道用户」为作用域。

同一个渠道用户再次与同一个智能体对话时，智能体可参考该用户的历史会话。

#### 7.4.5 运行规则

1. 记忆开关关闭时，智能体跳过历史会话记忆读取。
2. 记忆开关开启后，智能体根据记忆有效期和历史会话数读取历史上下文。
3. 当记忆有效期为自定义时，系统取有效期和历史会话数的交集。
4. 当记忆有效期为永久有效时，系统按历史会话数限制读取历史上下文。

### 7.5 模型异常话术

模型异常话术用于模型生成失败、响应异常或系统无法完成本轮回复时发送给用户。

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 模型异常话术 | 否 | 用户未填写时，系统使用默认文案 |

默认文案：

> 抱歉，我暂时无法完成本次回复，请稍后再试或联系人工支持。

运行规则：

1. 模型异常时，发送模型异常话术。
2. 模型异常话术发送后，会话保持。
3. 模型异常计入监控中的异常数据。

## 8. 流程

### 8.1 模块定位

流程用于定义智能体在特定业务场景下需要遵循的处理规则。

流程由流程名称、触发器和内容组成。智能体根据触发器判断是否参考该流程，并按照流程内容执行处理。

流程不是替代知识库和技能，而是调度知识库和技能。

### 8.2 页面结构

- 智能体详情 / 配置 / 流程
  - 左侧：流程列表
  - 右侧：流程编辑区

### 8.3 左侧流程列表

流程列表包含：

- 新建流程
- 流程项
  - 流程名称
  - 更多
    - 复制
    - 删除

#### 8.3.1 操作规则

| 操作 | 规则 |
|---|---|
| 新建流程 | 新建一条流程，右侧展示编辑区 |
| 复制 | 复制当前流程内容，生成一条新流程 |
| 删除 | 删除前弹出确认提示 |

### 8.4 右侧流程编辑区

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 流程名称 | 是 | 用于标识当前流程 |
| 触发器 | 是 | 描述什么情况下智能体应该使用该流程 |
| 内容 | 是 | 用自然语言描述智能体应如何处理该流程 |

#### 8.4.1 字段限制

| 字段 | 限制 |
|---|---|
| 流程名称 | 最多 50 字 |
| 触发器 | 最多 500 字 |
| 内容 | 最多 10000 字 |

### 8.5 触发器说明

触发器用于描述智能体在什么场景下参考该流程。

触发器不是简单关键词匹配，智能体会结合用户消息和上下文判断是否命中。

示例：

> 当用户询问订单状态、物流进度、发货时间或配送情况时，触发该流程。

### 8.6 内容编辑器

流程内容区支持基础格式化：

- 标题
- 加粗
- 有序列表
- 无序列表
- 引用
- 分割线
- 撤销 / 重做

### 8.7 内容示例

1. 先确认用户问题和必要信息。
2. 如果信息不足，逐项追问。
3. 如果需要查询外部系统，调用对应技能。
4. 如果需要参考政策，检索知识库。
5. 如果无法处理或用户要求人工，转人工。

### 8.8 流程与知识库、技能、转人工的关系

| 对象 | 作用 |
|---|---|
| 流程 | 定义业务处理步骤 |
| 知识库 | 提供事实依据 |
| 技能 | 执行外部能力调用 |
| 转人工 | 在流程判断需要人工介入时触发 |

流程内容可以描述以下动作：

- 追问用户
- 检索知识库
- 调用技能
- 转人工
- 回复用户

### 8.9 转人工规则

转人工规则配置在流程中。

流程内容可以用自然语言描述什么情况下需要转人工。

示例：

> 如果用户明确要求人工客服，转人工。

> 如果用户情绪激烈、连续表达不满，转人工。

> 如果技能调用失败，告知用户正在转接人工，并转人工。

当智能体执行流程并判断需要转人工时，系统根据当前渠道的转人工配置执行转人工。

### 8.10 运行规则

1. 流程属于单个智能体。
2. 流程编辑保存到智能体草稿配置。
3. 流程发布后影响真实渠道。
4. 智能体根据触发器判断是否参考流程。
5. 当多个流程可能匹配同一用户消息时，智能体根据触发器与当前用户意图的匹配度选择最相关流程。
6. 流程执行过程中可以检索知识库、调用技能或触发转人工。
7. 测试面板和会话记录中记录命中流程名称。

### 9.1 模块定位

### 9.2 页面结构

- 智能体详情 / 配置 / 技能
  - 添加技能
  - 技能列表

### 9.3 添加技能

点击「添加技能」后，展示可添加技能列表。

可添加技能范围：已启用技能。

### 9.4 技能列表字段

| 字段 | 说明 |
|---|---|
| 技能名称 | 展示技能名称 |
| 描述 | 展示技能描述 |
| 最近更新 | 展示技能最近更新时间 |
| 操作 | 更多 |

操作：

- 更多

### 9.5 运行规则

## 11. 防护措施

### 11.1 模块定位

### 11.2 页面结构

操作：

- 更多
  - 编辑
  - 复制
  - 删除

### 11.4 新建 / 编辑防护措施

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 防护措施名称 | 是 | 用于标识当前防护措施 |
| 提示词 | 是 | 描述什么情况算违规 |
| 违规时操作 | 是 | 结束会话 / 回复固定话术 |
| 固定回复话术 | 条件必填 | 当违规时操作为「回复固定话术」时必填 |
| 启用状态 | 是 | 默认开启 |

### 11.5 提示词说明

提示词用于描述防护措施的触发条件。

示例：

> 当用户要求智能体承诺充值返利、保证收益、预测结果或给出确定性收益承诺时，触发该防护措施。

> 当用户要求智能体提供账号密码、Token、密钥、内部接口地址或其他敏感凭证时，触发该防护措施。

> 当用户持续辱骂、威胁、骚扰或使用攻击性语言时，触发该防护措施。

### 11.6 违规时操作

| 操作 | 规则 |
|---|---|
| 结束会话 | 直接结束当前会话，跳过默认结束话术和渠道结束语发送 |
| 回复固定话术 | 直接发送固定话术，会话保持 |

固定回复话术示例：

> 抱歉，我无法协助处理该类内容。

> 该问题超出当前支持范围，请换一种方式描述你的需求。

> 为了保障服务安全，我暂时不能继续回应这个话题。

### 11.7 检查范围

防护措施检查：

1. 用户消息。
2. 智能体回复。

检查流程：

1. 用户发送消息。
2. 系统检查用户消息是否触发防护措施。
3. 触发防护措施时，按防护措施执行。
4. 未触发防护措施时，智能体继续处理。
5. 智能体生成回复。
6. 系统检查智能体回复是否触发防护措施。
7. 触发防护措施时，按防护措施执行。
8. 未触发防护措施时，发送智能体回复。

### 11.8 多个防护措施同时命中

1. 当多个防护措施同时命中时，结束会话优先于回复固定话术。
2. 当多个回复固定话术类防护措施同时命中时，系统选择匹配度最高的防护措施执行。

### 11.9 固定话术发送规则

防护措施触发「回复固定话术」后，直接发送固定话术。

固定话术跳过二次防护检查。

### 11.10 与流程、知识库、技能的关系

1. 防护措施优先于流程、知识库和技能。
2. 防护措施触发后，系统按防护措施配置执行。
3. 防护措施触发后，跳过知识库检索和技能调用。
4. 当流程内容与防护措施冲突时，以防护措施为准。

转人工Group 位于 Group 配置中。

#### 17.10.1 转人工分工

| 模块 | 职责 |
|---|---|
| 流程 | 描述什么情况下需要转人工 |
| 渠道 | 执行转人工到哪个 LiveChat Group |

#### 17.10.2 转人工执行规则

1. 流程判断需要转人工。
2. 系统检查渠道转人工配置。
3. 转人工开关开启，且转人工Group可用时，执行转人工。
4. 转人工开关关闭、未配置Group或转人工失败时，回复转人工失败话术。

#### 17.10.3 转人工成功规则

转人工成功后：

1. 智能体暂停自动回复。
2. 会话由人工继续接待。
3. 会话记录中记录转人工事件。

### 17.11 渠道保存规则

1. 渠道配置保存后按渠道配置生效。
2. 渠道配置独立于智能体发布流程。
3. 渠道保存时校验必填字段。
4. 渠道启用后开始接收对应 Group 的消息。

### 17.12 渠道删除规则

1. 删除渠道前弹出确认提示。
2. 删除渠道后，该渠道停止接收消息。

## 18. 智能体运行流程

### 18.1 消息处理顺序

1. 用户发送消息。
2. 渠道接收消息。
3. 系统找到渠道配置的接待智能体。
4. 系统读取该智能体的已发布配置。
5. 系统读取会话上下文和记忆配置。
6. 系统检查用户消息是否触发防护措施。
7. 用户消息触发防护措施时，按防护措施配置执行。
8. 用户消息未触发防护措施时，继续处理。
9. 系统判断是否命中流程。
10. 命中流程时，参考流程内容处理。
11. 未命中流程时，按智能体人设继续处理。
12. 根据需要检索知识。
13. 根据需要调用技能。
14. 根据需要触发转人工。
15. 生成智能体回复。
16. 系统检查智能体回复是否触发防护措施。
17. 智能体回复触发防护措施时，按防护措施配置执行。
18. 智能体回复未触发防护措施时，发送智能体回复。
19. 会话由智能体正常结束时，发送渠道结束语。
20. 系统记录会话、命中流程、命中知识、触发技能、触发防护措施、异常和转人工情况。

### 18.2 核心运行规则

1. 真实渠道只使用智能体已发布配置。
2. 测试面板使用智能体草稿配置。
3. 防护措施优先于流程、知识库和技能。
4. 防护措施触发后，系统按防护措施配置执行。
5. 流程用于指导智能体处理特定业务场景。
6. 知识库用于提供事实依据。
7. 技能用于执行外部能力调用。
8. 流程可以调度知识库、技能和转人工。
9. 环境变量只对当前智能体生效。
10. 转人工成功后，智能体暂停自动回复。

## 19. 会话结束规则

### 19.1 正常结束会话

当用户明确表示问题已解决、无需继续帮助，或智能体完成当前流程并确认用户无需继续协助时，视为正常结束会话。

正常结束会话时，发送渠道结束语。

### 19.2 转人工

当流程判断需要转人工时，系统根据当前渠道转人工配置执行转人工。

转人工成功后：

1. 智能体暂停自动回复。
2. 会话由人工继续接待。
3. 会话状态更新为已转人工。

### 19.3 防护措施结束会话

当防护措施触发「结束会话」时：

1. 系统直接结束当前会话。
2. 跳过默认结束话术。
3. 跳过渠道结束语发送。

### 19.4 模型异常

当模型异常时：

1. 发送模型异常话术。
2. 会话保持。
3. 记录模型异常事件。

## 23. V1 验收要点

### 23.1 智能体

1. 可以创建智能体。
2. 智能体列表以卡片形式展示。
3. 可以编辑基础信息、人设、记忆和模型异常话术。
4. 可以发布智能体。
5. 发布时校验智能体名称和系统提示词。
6. 测试面板使用草稿配置。
7. 真实渠道使用已发布配置。

### 23.2 流程

1. 可以新建、编辑、复制、删除流程。
2. 流程包含流程名称、触发器和内容。
3. 流程内容支持基础格式化。
4. 流程可以描述检索知识库、调用技能和转人工。
5. 会话记录中可以查看命中流程。

### 23.3 知识库

1. 可以添加 URL。
2. URL 必须以 https:// 开头。
3. 可以上传支持格式的文件。
4. 一个 URL 或一个文件生成一条知识文档。
5. 智能体可以添加已添加成功的知识文档。
6. 智能体详情中可以查看详情和从智能体分离。
7. 知识库文档内容更新后，对已添加该知识的智能体即时生效。

### 23.4 技能

1. 可以上传 .zip 或 .md 技能文件。
2. 上传成功后生成技能卡片。
3. 技能支持启用和关闭。
4. 智能体只能添加已启用技能。
5. 技能关闭或删除后，系统同步解除相关智能体的技能绑定关系。

### 23.5 防护措施

1. 可以新建、编辑、复制、删除防护措施。
2. 防护措施包含名称、提示词、违规时操作、固定回复话术和启用状态。
3. 防护措施检查用户消息和智能体回复。
4. 防护措施触发回复固定话术后直接发送固定话术。
5. 防护措施触发结束会话时直接结束会话，并跳过结束语发送。

### 23.6 环境变量

1. 可以新建、编辑、删除环境变量。
2. 环境变量包含变量、值、描述。
3. 变量遵循命名规则。
4. 可通过 {{变量}} 引用。
5. 环境变量只对当前智能体生效。

### 23.7 渠道

1. 渠道页面顶部展示 LiveChat 类型。
2. LiveChat 列表展示渠道名称、接待智能体、启用状态、最近更新和操作。
3. 新建渠道时先配置渠道名称和选择智能体。
4. 选择智能体仅展示已发布智能体。
5. 可以配置 Account ID 和 Access Token。
6. 可以校验并拉取 Group。
7. 可以配置接待Group和转人工Group。
8. 可以配置开场白、热门问题、结束语。
9. 可以配置转人工开关和转人工失败话术。
10. 渠道配置保存后生效。

### 23.8 监控

1. 数据概览支持时间范围和渠道筛选。
2. 数据概览展示会话数、消息数、转人工数、异常数、平均响应时长、流程触发 Top、技能触发 Top、防护措施触发 Top、异常类型分布。
3. 会话记录支持时间范围、渠道、会话状态、命中类型筛选。
4. 会话详情展示基础信息、对话内容和命中详情。
5. 命中详情展示命中流程、命中知识、触发技能、触发防护措施、转人工、模型异常、结束语发送情况。
