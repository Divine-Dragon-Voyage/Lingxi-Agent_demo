## 1．项目概述

### 1.1 背景与问题

客服运营人员需要创建不同服务场景的 AI 客服，并维护其知识文档、团队归属和人工转接关系。分散维护会导致服务范围、可用知识与转人工目标难以核对。

灵犀智能体为客服运营人员和团队管理者提供 AI 客服配置平台，通过「客服管理、知识库、团队」完成最小配置闭环。

### 1.2 产品定位与约束

产品是面向企业客服场景的 AI 客服配置平台。本期聚焦 AI 客服、知识库和团队的配置管理，不提供账号认证、组织权限、技能、渠道、流程、防护措施、环境变量、测试面板与监控能力。

### 1.3 目标用户

| 用户 | 场景 | 目标 |
|---|---|---|
| 客服运营人员 | 配置订单、售前、售后、会员等 AI 客服 | 快速维护客服能力和知识 |
| 团队管理者 | 管理人工客服与 AI 客服协作团队 | 维护成员与接待优先级 |

### 1.4 MVP 范围

**包含：**AI 客服管理、PDF 知识文档、团队管理、草稿与发布、文档处理状态、危险操作确认和数据持久化。

**不包含：**真实用户与权限、LLM 与知识检索、真实渠道和人工转接、真实文件解析；技能、渠道、流程、防护措施、环境变量、测试面板、监控等隐藏能力及其历史代码不属于当前用户可达产品范围；不支持 URL、非 PDF 文档和文档编辑。

## 3．功能需求详述

### 3.1 客服管理

**目标：**管理全部 AI 客服，并进入客服配置。

| 区块 | 内容与规则 |
|---|---|
| 搜索 | 按 AI 客服名称搜索 |
| 状态筛选 | 全部状态、已发布、未发布；与搜索同时生效 |
| 客服卡片 | 头像、名称、发布状态、简介、最近更新时间；整卡和「配置」均可进入详情 |
| 更多操作 | 复制 AI 客服、删除 AI 客服 |

无匹配结果时展示空状态和「新建 AI 客服」入口。

**卡片状态规则：**头像右下角显示小红点，表示该 AI 客服当前处于「在线」状态；不显示小红点表示离线。小红点由「接受聊天」开关控制；该开关只能在 AI 客服已发布后开启，因此小红点同时表示已发布且正在接受聊天。

#### 新建／编辑 AI 客服

| 字段 | 必填 | 规则 |
|---|---|---|
| 名称 | 是 | 最多 50 个字，在详情页「个人资料」中维护 |
| 简介 | 否 | 单行文本，描述用途、能力范围或服务场景 |
| 团队 | 是 | 支持搜索、多选、清空、逐项移除与全选；始终自动加入通用团队 |
| 头像 | 否 | 默认占位头像；点击头像选择图片，头像是唯一上传入口 |

点击「新建 AI 客服」后，系统直接生成未发布空白草稿、默认加入通用团队与开启记忆，并跳转至详情「个人资料」；名称与团队在发布前必须有效。基础资料在详情页自动保存，不提供独立编辑弹窗。

#### 复制与删除

复制生成名称为「原名称_副本」的未发布客服；原名称为空时使用「未命名_副本」。副本保留原配置但关闭接受聊天。删除前需二次确认；确认后删除客服，并从所有团队成员中移除。

### 3.2 AI 客服详情／AI 客服配置

**入口：**从客服卡片进入。详情导航仅含「个人资料」「知识库」。

#### 顶部操作区

| 字段／操作 | 定义 | 交互与规则 |
|---|---|---|
| 返回 | 返回客服管理列表 | 点击后离开详情页，不改变当前草稿 |
| AI 客服名称 | 当前客服名称；未填写时展示「未命名」 | 与个人资料中的名称实时同步；名称、简介、团队和头像在「个人资料」中维护 |
| 发布状态 | 已发布／未发布 | 未发布仅存在草稿；已发布存在已发布配置快照 |
| 最近保存 | 当前草稿最后一次成功保存的时间 | 仅在详情页自动保存成功或基础信息弹窗点击保存成功后更新；不等同于发布时间 |
| 接受聊天 | 是否让已发布客服进入在线接待状态 | 默认关闭；未发布时禁止开启并提示先发布；开启后列表头像显示小红点，关闭后隐藏 |
| 发布 | 将当前草稿生成为已发布配置 | 每次点击均以当前草稿覆盖已发布快照，并更新最近保存时间 |

#### 人设

| 字段 | 规则 |
|---|---|
| 头像与名称 | 同一行展示：左侧为头像上传入口，右侧上方为「名称」字段名、下方为名称输入框；名称必填 |
| 简介 | 与头像／名称并排展示，使用单行输入框 |
| 系统提示词 | 可选，最多 10,000 字 |
| 团队 | 位于系统提示词下方，必填，支持多选；始终自动加入通用团队 |
| 回复语言 | 与用户语言相同、中文、英文、日文、泰文、越南文 |
| 回复风格 | 自然、正式、简洁、耐心、热情 |

详情页内字段修改后自动保存为草稿；新建 AI 客服的默认人设为：系统提示词为空、回复语言为「与用户语言相同」、回复风格为「自然」。系统提示词空值时使用单行高度，输入后随内容自适应增长，最多显示 8 行后内部滚动，不支持手动拖拽调整高度。保存中不更新最近保存时间；保存失败时保留用户输入、展示失败提示并允许再次编辑触发重试。

#### 记忆

| 字段 | 默认值 | 规则 |
|---|---|---|
| 记忆开关 | 开启 | 关闭时隐藏记忆有效期和历史会话数；重新开启后恢复已保存值 |
| 记忆有效期 | 7 天 | 支持永久有效或 1—365 天自定义有效期；选择永久有效时隐藏数值设置 |
| 历史会话数 | 10 轮 | 支持 1—30 轮；只在记忆开启时可编辑 |

#### 转人工

| 配置 | 规则 |
|---|---|
| 转人工开关 | 默认开启；关闭后不保存转人工目标 |
| 自动 | 默认选中；先在在线主要成员中轮询，主要成员均不可接待时再在在线备份成员中轮询；无人在线时执行转人工失败兜底 |
| 转移到指定团队 | 必须选择有效团队；仅选中该方案时展示团队选择器 |

#### 发布与接受聊天

| 操作 | 条件 | 结果 |
|---|---|---|
| 发布 | 名称非空；至少存在一个团队；指定团队模式已选择有效团队 | 将草稿复制为已发布配置，状态改为已发布 |
| 开启接受聊天 | 客服已发布 | 更新接受聊天状态并显示在线提示 |
| 未发布时开启 | 客服未发布 | 阻止并提示先发布 |

已发布 AI 客服的系统提示词、记忆、转人工和知识文档绑定修改后只保存到草稿；必须再次点击发布，才覆盖已发布配置并影响线上接待。

#### 预览与测试

详情页右侧提供预览与测试区，用于验证当前草稿配置的基础对话表现。用户可拖动分隔条在 320—640px 范围内调整宽度；空态展示 AI 客服头像、名称和输入引导；输入消息后按 Enter 或点击发送，按时间顺序展示用户消息与 AI 回复。测试仅使用当前草稿，不写入线上会话，也不触发发布。

### 3.3 AI 客服详情／知识库绑定

**目标：**维护当前客服可使用的 PDF 文档。

已绑定列表展示 PDF 图标、名称、创建者、创建时间和移除操作，支持按名称搜索。移除需二次确认，仅解除当前客服绑定，不删除源文档。

点击「绑定文档」后，只列出处理成功、尚未绑定且满足搜索条件的 PDF。点击候选项即完成绑定；弹窗可继续「添加文档」。处理中、失败或非 PDF 文档不可绑定。

### 3.4 知识库

**目标：**管理可被 AI 客服绑定的 PDF 文档。

| 字段 | 规则 |
|---|---|
| 名称 | PDF 图标与文档名称 |
| 创建者、创建时间 | 展示文档元数据；创建时间缺失时使用最近更新时间 |
| 状态 | 处理中、处理成功、处理失败 |
| 操作 | 处理中和处理成功时提供删除文档；处理失败时提供重新处理和删除文档 |

支持按名称搜索，每页最多 8 条。

#### 添加与删除文档

| 场景 | 规则 |
|---|---|
| 添加 | 点击或拖放，可多选；仅 PDF，单文件不超过 100 MB |
| 处理 | 创建处理中记录，按上传→切片→数据处理→处理成功流转 |
| 处理失败 | 显示失败状态和失败原因；失败文档不可绑定至 AI 客服 |
| 重新处理 | 仅处理失败文档可操作；保留原文档记录，清空原失败原因并重新进入处理中状态 |
| 不合法文件 | 不创建记录并显示错误提示 |
| 删除 | 二次确认后删除源文档，并解除全部 AI 客服在草稿和已发布配置中的绑定 |

不提供文档编辑、URL 添加和撤销删除。

### 3.5 团队

**目标：**维护 AI 客服转人工或协同接待的成员集合。

| 字段 | 规则 |
|---|---|
| 名称 | 方形彩色文字头像、名称、成员数量；可进入详情 |
| ID | 纯数字字符串；ID 值后提供复制入口，默认隐藏，悬浮 ID 单元格或键盘聚焦时显示；点击复制当前团队 ID，并短暂显示复制成功状态 |
| 在线成员 | 当前在线成员数／团队成员总数；人工客服与 AI 客服统一计入团队成员 |
| 操作 | 编辑；非内置团队可删除 |

支持按名称搜索。内置「通用」团队固定置顶。

#### 新建与维护团队

| 能力 | 规则 |
|---|---|
| 新建 | 团队名称必填、最多 32 个字；成员可为空 |
| 选择成员 | 可选人工客服和 AI 客服，支持搜索、全部／人工客服／AI 客服筛选与全选 |
| 编辑名称 | 非内置团队可修改，最多 32 个字 |
| 添加／移除成员 | 非内置团队可维护；添加时不重复展示已在团队内的成员 |
| 优先级 | 每个成员可设为主要或备份；主要表示团队内优先接待 |
| 保存 | 有改动时展示固定操作栏，可取消或保存 |

通用团队固定包含全部人工成员和 AI 客服，不可删除、改名、增删成员或调整优先级。

删除非内置团队前需二次确认。若任一 AI 客服草稿的指定团队转人工正在引用该团队，阻止删除并提示先修改配置。

## 4．关键流程与关系规则

### 4.1 AI 客服创建与发布

```text
新建客服 → 填写基础信息与团队 → 生成未发布草稿
→ 配置人设、记忆、转人工 → 校验 → 发布 → 开启接受聊天
```

### 4.2 知识上传与绑定

```text
上传 PDF → 格式与大小校验 → 文档处理成功 → 在客服详情中选择并绑定
```

### 4.3 团队关系

```text
AI 客服选择团队 → 自动加入通用团队 → 团队成员同步
→ 配置自动或指定团队转人工 → 发布时校验团队依赖
```

AI 客服详情内配置修改自动保存至草稿；基础信息弹窗通过明确保存操作更新草稿。发布把草稿快照复制为已发布配置；运行时读取已发布配置；草稿修改在再次发布前不影响线上接待。

## 5．数据模型概要

| 实体 | 核心字段 | 说明 |
|---|---|---|
| AI 客服 | id、name、description、avatar、teamIds、acceptingChats、status、draft、published、lastSavedAt、publishedAt | `teamIds` 始终包含通用团队；接受聊天开启表示在线 |
| 草稿配置 | prompt、language、style、memoryEnabled、memoryDays、historyRounds、transferToHuman、knowledgeIds | 当前可编辑配置 |
| 知识文档 | id、type、name、source、size、creator、status、content、createdAt、updatedAt | 当前用户入口只创建 PDF |
| 团队 | id、name、builtin、members、createdAt、updatedAt | ID 为纯数字；builtin 标识通用团队 |
| 团队成员 | id、kind、name、serviceId、acceptingChats、priority | kind 为 human 或 ai；接受聊天开启表示在线；priority 为 primary 或 backup |

## 6．状态、校验与待确认事项

| 场景 | 规则 |
|---|---|
| AI 客服未发布 | 只能编辑草稿，不能开启接受聊天 |
| 知识文档处理中 | 不作为可绑定候选 |
| 知识文档处理失败 | 展示失败原因；不可绑定；支持重新处理或删除 |
| 非 PDF 或超过 100 MB | 拒绝上传并提示原因 |
| 删除文档 | 二次确认并解除所有绑定 |
| 删除被指定团队引用的团队 | 阻止删除 |
| 危险操作 | 删除客服、文档、团队和移除绑定均需确认 |

**待确认：**文档失败与重试规则；多个主要成员的真实路由顺序；无在线成员时的自动转人工兜底；发布后草稿与已发布配置的真实生效策略；团队删除是否应同时校验已发布配置；真实角色权限、数据隔离、文件安全与审计。

## 7．验收标准

| 验收项 | 通过标准 |
|---|---|
| 信息架构 | 侧边栏仅展示 AI 客服（客服管理、知识库）与团队，核心页面均可到达 |
| AI 客服 | 可新建、编辑、筛选、复制、删除、自动保存草稿并发布 |
| 发布 | 未发布客服不可接受聊天；指定团队缺失时不可发布 |
| 知识库 | 仅接受 100 MB 以内 PDF；处理成功文档可搜索、绑定和删除；处理失败文档可查看原因并重新处理 |
| 文档关系 | 移除只影响当前客服；删除源文档解除全部绑定 |
| 团队 | 可新建、搜索、编辑、维护成员与优先级；通用团队受保护 |
| 删除保护 | 删除操作确认生效；被指定转人工引用的团队不可删除 |
| 持久化 | 对客服、团队、文档的操作刷新后保留 |

## 8．后续迭代假设

- 明确真实运行时与组织权限后，再决定是否恢复技能、渠道、流程、防护措施、环境变量和监控入口；
- 接入真实解析服务后补充文档失败态、重试、版本与处理日志；
- 接入真实人工路由后补充成员负载、在线状态来源、优先级冲突和失败回退；
- 接入后端前明确草稿／已发布配置的版本管理与回滚策略。
