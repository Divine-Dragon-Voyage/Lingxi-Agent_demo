# 工作流演示增量需求

本需求经用户确认，优先于历史 PRD 中的富文本流程设计。保留现有产品壳层、Arco Design、设计 Token 和其他模块；只提供可演示前端，不接真实后端、模型或外部接口。

## 页面与操作

- 资源中心工作流：名称（含发布状态）、触发器、创建者、操作四列；支持名称／触发器搜索、分页、新建、编辑、复制、二次确认删除。
- 新建与基础信息弹窗：名称必填，最多 50 字；触发器必填，最多 500 字。创建者自动填入当前演示用户。新建后进入画布；复制生成独立草稿，不复制发布状态与绑定关系。
- 画布：顶部返回、名称、编辑基础信息、发布状态、保存反馈、发布按钮；中间点阵画布；右侧节点库／选中节点配置。使用 React Flow 的拖拽、连线、平移、缩放、适应视图；支持点击添加及拖入节点。删除节点／连线需确认，开始节点不可删除。
- 节点：开始、结束、AI 任务（提示词）、信息收集（问题、字段、必填）、接口调用（方式、地址、参数、模拟 JSON 返回）、条件分支（字段、运算符、比较值、默认出口）、发送回复（内容）、转人工（团队、话术）。首版条件分支为满足／不满足两出口。
- 不提供模板市场、客群、多语言、工单、循环、真实执行引擎或版本历史。

## 保存与发布

- 草稿的名称、触发器、节点配置、位置与连线自动写入统一 reducer 并持久化至 localStorage；刷新可恢复。保存失败保留内存中的编辑，展示重试入口。
- 草稿与已发布快照分离。状态为草稿、已发布、已发布有修改；发布后继续编辑不覆盖已发布快照。
- 发布校验基础信息、节点必填项、开始与结束、连通性、分支出口和无循环；错误可定位节点。校验通过后确认发布，保存失败时不可发布。
- 再次发布更新同一工作流的已发布快照，已绑定 Agent 使用最新发布版。
- 被任一 Agent 草稿或已发布配置引用的流程不能删除；解绑草稿后若已发布配置仍引用，须发布 Agent 配置后才能删除。

## Agent 绑定与解绑

复用知识库绑定页结构和操作节奏，首版 ASCII 如下（随用户确认的绑定需求同步实施）：

```text
+----------------------------------------------------------+
| 工作流                                    [＋ 绑定工作流] |
| [搜索工作流名称或触发器                             ]     |
| 名称             触发器             创建者       操作     |
| 订单查询         查询订单状态        Owen         查看 删除 |
+----------------------------------------------------------+
| 绑定工作流                                           ×   |
| [搜索工作流                                        ]     |
| [ ] 订单查询   已发布                                     |
|     用户询问订单或物流进度                                |
|                                  [取消] [绑定所选工作流] |
+----------------------------------------------------------+
```

- 绑定弹窗仅展示存在发布快照且当前未绑定的流程；支持搜索、多选、确认绑定。名称和触发器展示已发布内容。
- 绑定、解绑修改 Agent 草稿，沿用 Agent 现有发布生效规则。解绑需二次确认，不删除源工作流。
- 同一流程可供多个 Agent 绑定。选择已发布有修改的工作流时绑定其最新成功发布版，不绑定未发布草稿。
- 空列表、搜索无结果、无可绑定流程、加载与失败反馈均需可辨识；查看返回时保留 Agent 路径。

## 验收

构建与 lint；浏览器验证新建、字段校验、节点添加／拖动／配置／连线／删除、缩放、自动保存与刷新、发布校验及成功、草稿与发布版隔离、复制、删除引用保护、Agent 绑定／取消／解绑、刷新保持。桌面与窄屏检查无页面溢出、表单遮挡和空白画布。
